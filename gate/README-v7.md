# NSD 게이트 동행 적합성 연구 — V7 통합판

경로: https://su9ar0319.github.io/nsd-sensory-lab/gate/

## V7에서 달라진 점
- 본 검사: 전술 점수 16문항 + 장면 선택 8문항 = 기본 24문항
- 점수/행동이 애매하면 보조 문항 최대 4개 제공(비워둬도 저장 가능)
- 감각 간섭 공개 기록: \`sensoryPublicProfiles\`
- 공명 색채·잔향 공개 기록: \`publicProfiles\`
- 캐릭터 이름이 같아도 절대 자동 합치지 않음. 각 공개 캐릭터를 직접 선택한 경우에만 연계
- 기존 공개 기록은 읽기 전용이며 원본 40개 설문 응답은 불러오지 않음
- 개인 전술 보고서는 V6 방식의 장문 8영역(행동 동기·현장·갈등·가상 사례·동행·사후 회고·차별점·한마디)으로 출력
- 기존 2인 분석과 3인 7단계 작전 시뮬레이션은 유지. 다만 새 설문에서 실제 답한 상황은 8개뿐이므로 직군 상황 일부는 반복 참조함

## 연결 현황
색채·감각·게이트 세 사이트 모두 **같은 Firebase 프로젝트 설정**을 이용합니다.
이 저장소의 \`gate/index.html\`은 기존 \`../firebase-config.js\`를 그대로 불러옵니다.
신규 공개 정보는 \`gatePublicProfiles\`, 원본 본인 정보는 \`gateUsers/{uid}/records\`에 저장합니다.

Firebase 실시간 저장을 사용하려면 기존 Firestore Security Rules 안에
\`gate/firestore-v7-additions.rules.txt\`의 두 \`match\` 블록을 추가한 후 Firebase 콘솔에서 게시해야 합니다.
기존 감각·색채 규칙은 삭제하거나 대체하지 마세요.
Firebase Authentication의 익명 로그인 제공업체가 켜져 있어야 합니다.

## 검증 순서
1. 게이트 사이트 열기. 브라우저 개발자 콘솔 오류 여부 확인
2. 감각·색채 공개 목록 갱신 후, 공개된 캐릭터를 각각 선택 (없으면 건너뛰기)
3. 16개 1~10점 설문과 8개 상황 선택. 필요하면 추가 4문항 선택
4. 비공개 저장 후 본인 기록에 V7 장문 결과가 표시되는지 확인
5. 공개 체크하여 추가 기록 저장. 시크릿 창에서 같은 캐릭터의 공개 보고서가 보이는지 확인
6. 센티넬 2명, 가이드 1명의 기록으로 2인/3인 분석을 각각 시험
7. 원본 감각·색채 캐릭터를 비공개 처리했다면 새로고침 시 연동 해설이 더 이상 표시되지 않는지 확인

## 주의
- 개발자가 생성한 V6 장문 시안을 확장한 자동 결과지로, 공식 게임 능력이나 실제 수치를 예측하지 않습니다.
- 현재 테스트는 코드 구문과 시뮬레이션 단위 테스트 수준이며 Firebase 원격 실서비스의 실제 저장·권한 성공은 아직 확인되지 않았습니다.
- 감각·색채 결과로 전술 점수를 부풀리지 않습니다. 감각은 반응, 색채는 가치관/행동 동기 해석용입니다.
- 다른 사이트에서 등록자 권한을 갖게 되는 것은 아니며 공개 기록만 열람합니다.
