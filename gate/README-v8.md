# NSD 게이트 동행 적합성 연구 V8 — 개별 해석 엔진

## 유지 기능
- 기존 기본 24문항 + 선택형 4문항
- 기존 Firestore gateUsers, gatePublicProfiles 및 감각·색채 공개 기록
- 12개 전술 축과 점수 계산, 2인/3인 수치 시뮬레이션
- 모노톤 + 딥레드 C 테마

## V8 개선 사항
- 1인: 주력·보조·취약 축 외에 보호·지속·돌파·검증·조율·통제·변경·귀환 동기의 우선순위를 분석
- 8개 상황 선택을 각각 맥락에 맞게 반영하는 9개 영역 장문 해설
- 같은 1·2위 전술 유형이라도 나머지 점수와 상황 선택이 다르면 해설 내용이 달라짐
- 이름과 프로필 ID를 무작위 문장 선택에 사용하지 않음
- 2인: 서로의 동기와 상황별 선택이 일치하거나 달라지는 지점을 양방향 분석에 반영
- 3인: 7개 단계에서 세 사람의 선택 방향, 동기, 시뮬레이션 자원 변화와 제3자 역할을 추가 해석
- 감각/색채: 현재 공개 상태인 기록을 사용자가 선택한 ID로 조회. 각 연구소의 상위 두 축과 세부 문항군 차이를 전술 선택과 **보조적으로** 비교
- 다른 연구소의 점수는 게이트 전술 능력이나 자원 수치에 더하지 않음

## 검증 범위
- 가상 캐릭터 120명(각기 다른 응답) → 120개 해설
- 주력·보조 축이 동일한 가상 캐릭터 80명 → 80개 해설
- 전술 점수는 같고 상황 선택만 다른 가상 캐릭터 70명 → 70개 해설
- 센티넬만 3명, 가이드만 3명, 혼합 3명의 7단계 시뮬레이션 실행
- 감각·색채 공개 기록을 둘 다 연결한 모의 자료 및 공개 여부/직군 불일치 모의 자료 검증
- 자동 보고서 간 차이를 확인하는 시험이지 캐릭터 해석의 정확도를 과학적으로 검증한 것은 아님

## 서연림 실제 연동 확인
1. 게이트 연구소에서 서연림 1인 보고서를 연다.
2. 하단의 "연구자용 수치 및 상황 선택 확인"에서 감각·색채 모두 연결 상태인지 확인한다.
3. "08 / CROSS REPORT" 영역에서 두 연구소의 상위 축을 읽는 교차 해설이 나타나는지 확인한다.
4. 연결되지 않았다면 신규 검사/수정 화면에서 각 공개 캐릭터를 명시적으로 선택한다.
5. 공개 목록을 읽을 수 없어도 기존 연결 ID는 보존되지만 실제 공개 상태를 확인할 수 없으면 해당 해설은 표시되지 않는다.

**주의:** 이번 코드 작업은 실제 서연림 Firestore 점수를 직접 조회하지 않았다. 공개 데이터 연동 동작은 가상 자료로 검증했다. 실제 점수의 해설 여부는 연구소 브라우저에서 확인해야 한다.

## 세계관 제약
- 센티넬의 부하도와 폭주 위험은 실제 게임 수치를 예측하지 않는다.
- 가이드는 실제 가이딩 수행 시 가이딩 잔량이 소모되고, 0이 되면 공명 고갈 상태다.
- 상시 정신 링크나 자동 가이딩을 전제하지 않는다.
